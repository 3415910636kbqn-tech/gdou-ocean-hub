# 海大教务助手 (GDOU Ocean Hub)

面向 **广东海洋大学 (GDOU)** 在校生的本地零留存教务助手 Web 应用，基于 [GDOU-haida-schedule](https://github.com/aoligei233666/GDOU-haida-schedule)（GPL-3.0）的教务直连与解析核心重构并全面升级 UI。

## 核心特点

- **纯本机运行 · 零服务器 · 绝不收集信息**：所有请求均从你自己的设备直连海大官方域名（`*.gdou.edu.cn`），无任何第三方中转服务器；本地仅用内存临时 Cookie 罐完成一次拉取，同步结束后自动调用官方注销接口并销毁所有凭据与 Cookie。
- **无需购买校园网（校外/校内自适应）**：自动探测 `netcheck.gdou.edu.cn/go.php?code=jw`，校外自动走海大微门户 `wfw.gdou.edu.cn` 通道，校内直连 `jw.gdou.edu.cn`，支持图形验证码、企业微信/短信多因子认证（MFA）以及校外子会话二次握手。
- **全新 Oceanic Bento UI（支持深色模式 & 手机/电脑自适应）**：
  - **课表视图**：周课表网格 + 今日课表速览 + 实时“正在上课/下一节课”提醒栏 + 非本周切换 + 重叠课程聚合查看 + 手动添加课程 + 一键导出 `.ics` 系统日历。
  - **考试安排**：最近一场考试倒计时 Hero 卡片 + 考场与**座位号高亮** + 即将到来/已结束筛选 + 手动添加测验 + 导出考试日历 `.ics`。
  - **成绩与绩点仪表盘**：5.0 制总 GPA、必修课 GPA、加权均分、已获学分与通过率 + 各学期 GPA 趋势面积图 + 5 档成绩分布 + 课程性质学分构成 + **期末绩点模拟器（What-If Simulator）** + 全量课程明细搜索/筛选/排序。

## 快速启动

```bash
npm install
npm run dev
```

启动后在浏览器打开 `http://127.0.0.1:5173` 即可使用！
- 初次打开默认载入海大示例数据，方便直接预览所有页面功能。
- 点击右上角 **「教务同步」** 即可输入学号与统一身份认证密码，一键拉取你本人的真实课表、考试安排与历年成绩。

## 生产构建与单进程运行

```bash
npm run build
npm start
```

构建后仅需运行 `npm start`，访问 `http://127.0.0.1:3456` 即可同时提供前端页面与本地零留存同步 API。
